# AI Portfolio Website

## Overview
This is an AI-powered personal portfolio website featuring an interactive ChatGPT-style chatbot that answers questions about my background, experience, and projects. The website serves as both a traditional portfolio showcasing my work and an innovative demonstration of my skills in AI integration and modern web development.

## Key Features

### AI Assistant
- Interactive chatbot powered by OpenAI's GPT-4o model
- Custom Retrieval-Augmented Generation (RAG) system for accurate responses
- Semantic search using OpenAI's text-embedding-ada-002 model
- Cosine similarity scoring with fine-tuned heuristics
- Dual-layer chunking system for context resolution

### User Experience
- ChatGPT-style UI with dynamic message typing animation
- Mobile-responsive design
- Animated modals and transitions
- Form-to-email integration for contact functionality

### Technical Implementation
- Built with Next.js and React
- CSS Modules for styling
- Context API for state management
- Error handling for rate limiting and API failures
- SEO optimization with metadata and Open Graph support

## Project Sections
- **Home**: Chat interface with AI assistant
- **About**: Personal background and skills
- **Experience**: Work history and accomplishments
- **Projects**: Showcase of technical projects
- **Resume**: Downloadable resume and skills summary
- **Contact**: Form to get in touch

## Purpose
This portfolio website demonstrates my technical abilities in full-stack development, AI integration, and user experience design. It serves as both a professional showcase and a practical example of implementing AI in web applications.

The AI assistant can answer questions about my education, skills, projects, and work experience, providing recruiters and visitors with an engaging way to learn about my qualifications and background.
